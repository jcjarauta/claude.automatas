# Baseline del proyecto

El documento de referencia conceptual —principios invariantes, ontología de la
máquina, núcleo de ingeniería transversal, envolventes por clase, sistema de
módulos y acoplamiento, catálogo de módulos, familias de máquina, líneas de
negocio e hitos— se mantiene como documento vivo y editable en Claude, no en
este repositorio.

**Título:** Baseline · máquinas programables

Se edita y comenta allí. Este fichero existe para que las referencias desde
`CLAUDE.md` no queden colgando y para dejar constancia de dónde vive.

## Lo imprescindible, en seis líneas

1. Todo programa es función de θ, el ángulo del eje maestro. Nunca del tiempo.
2. Máquina y programa se separan siempre: plataforma más cartucho.
3. La amplificación va de la memoria gruesa al resultado fino.
4. Toda viabilidad es una envolvente calculable.
5. La energía se puede desacoplar en el tiempo mediante un acumulador.
6. La resistencia que siente la persona es una variable de diseño.
